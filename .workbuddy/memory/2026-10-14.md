## 2026-10-14 傍晚：修复「真机导出提示打开分享面板失败」
- 根因：wx.shareFileMessage 官方限制「仅在点击行为时调用」——必须与用户点击手势同一同步调用栈。原实现放在 fs.writeFile 的异步 success 回调里调用，真机报 "shareFileMessage:fail can only be invoked by user TAP gesture."（开发者工具模拟器同样报此错）。异步调用形式（writeFile/downloadFile/setTimeout 回调内）均违反限制。
- 修复：exportFileMp 改用 fs.writeFileSync 同步写入（备份 JSON 很小），紧接着直接调 shareFileMessage，整条链同步（tap → exportData → exportFileMp → writeFileSync → shareFileMessage）；settings.vue MP 分支去掉 showLoading（避免中间插入 UI 调用，且写入瞬时完成）；失败文案区分 TAP gesture / devtools / 其他，失败时 console.warn 原始 errMsg 便于 vConsole 排查。
- 依据：微信官方文档「限制:仅在点击行为时调用」+ 社区实践（writeFileSync + 同一按钮 click 内直接调用是唯一可靠模式）。
- 门禁全绿（71 测试），mp-weixin 构建通过。教训：小程序敏感 API（shareFileMessage/chooseMessageFile 等）严禁放进异步回调，必须与点击同栈调用。
