## 云同步：跨设备不实时 + 手机登录 Connection reset

### 现象
1. 手机（只读/第二台设备）停在页面上时，主账号新增的课程不出现，退出重登才刷新。
2. 手机登录报 `request:fail abort statusCode:-1 Connection reset`，电脑（开 VPN）正常。

### 结论（已实测）
- 第 2 条不是代码问题：`api.fqcdan1001.dpdns.org` 在国内网络直连（80/443）被 RST。
  - 同 IP `104.21.23.173` 换 SNI 为 `www.cloudflare.com` → 200；`developers.cloudflare.com` 直连 200；
  - 说明 Cloudflare 边缘可达，是 `dpdns.org` 这个免费域名被针对性重置；`workers.dev` 同样被墙（解析到 103.252.114.101）。
  - 结论：换自有域名挂 Cloudflare 即可直连，后端不必迁移。
- 第 1 条是客户端轮询缺失 + 同步锁被持久化：
  - 原来只有只读账号在 App `onShow` 时 `pullSnapshot()`，页面停留期间永不拉取；
  - `useSyncStore` 的 `syncing` 被 `persist: true` 持久化，进程在同步中途被杀会永久为 true，之后所有 pull/push 静默跳过（hydrate 不走这个守卫，所以「重登能更新」）。

### 改动
- `src/store/sync.ts`：新增 `serverVersion`；`persist` 改为 `paths: ['account','role','lastSyncAt','serverVersion']`，不再持久化 `syncing`。
- `src/sync/sync-service.ts`：新增 20s 前台轮询 `startAutoPull/stopAutoPull`、`syncNow`、脏锁回收（40s）、`pendingLocalChange`（写者有未上传改动时拒绝被服务端覆盖）、push 后回写 serverVersion、按版本号跳过无变化的整份覆盖。
- `src/App.vue`：`onShow` 启轮询，`onHide` 停轮询 + 立即 push。
- `src/api/sync.ts`：`saveSnapshot` 返回 `{version, updatedAt}`；网络类 errMsg 归一为「无法连接同步服务器」。
- `src/pages/settings/settings.vue`：「账号与同步」新增「立即同步」。
- 测试同步更新（81 passed）；type-check / lint 全绿。

## 追加：dpdns.org 无解，改走 Pages 反代

- 随机造的 `*.dpdns.org` 子域（zzz-test-9137 / sync-test-5521）在真实 CF IP 上同样是 TLS 握手 RST → **整段 dpdns.org 被封**，换子域无效。
