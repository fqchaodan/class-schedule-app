## 修复：启动报错 useCourseStore is not defined（连锁 $setup.longDate/coursesOf 报错）
- 根因：vite.config.ts 的 AutoImport dirs 只配 `['src/hooks']`，漏了 `src/store`，且手维护的 src/types/auto-import.d.ts 无 store 声明 → useCourseStore/useAppStore 运行时 undefined，setup 首行抛错导致模板 $setup.longDate/coursesOf 全部 not a function（连锁反应，非模板问题）。
- 修复：vite.config.ts AutoImport dirs 改为 `['src/hooks', 'src/store']`；auto-import.d.ts 手动补 useAppStore/useCourseStore/useRecycleStore/useTemplateStore/useTokenStore/useUserStore 的 const 与 ComponentCustomProperties 声明（两处，按字母序）。
- 注意：ViteRestart 只监听 vite.config.js，改 vite.config.ts 后需手动重启 dev；验证 9003 端口全部页面 200。
